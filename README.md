# 光谱颜色模拟器

反射率 × 光源 → 颜色。输入一条材料反射率曲线和一个光源的光谱，算出这个材料在这个
光源下看起来是什么颜色，给出 XYZ / Lab / sRGB / Display P3 / Adobe RGB / BT.2020 数值、色块、
光谱曲线，能和实测值算色差 ΔE，也能一次批量算多组（多反射率×单光源 或 单反射率×多光源）。

纯静态网页：不需要安装 Python、不需要服务器、不需要联网。

---

## 1. 怎么打开

**最简单**：双击 `index.html`。

- macOS：双击 `启动.command`（会用默认浏览器打开）
- Windows：双击 `启动.bat`
- 推荐浏览器：Chrome / Edge。Safari 对 `file://` 的本地存储限制更严，可能无法自动保存库。
- 发给同事：整个文件夹打包（去掉 `.venv/`）发过去，解压双击即可。

数据存在浏览器的 localStorage 里。**换电脑或清浏览器缓存前，先点右上角「导出库」**，
会下载一个 `library.json`，以后用「导入库」恢复。

## 2. 三个功能

### 2.1 导入与管理

- **导入 CSV**：选择文件或直接粘贴表格，工具会自动猜：表头行数、哪列是波长、哪列是数值、
  起始波长和步长、单位（0~1 / 0~100% / SPD）。猜完显示一、二行原始数据 + 预览曲线，
  每个字段都能手动改。
- **手动输入**：每行 `波长 数值`，与 CSV 走同一套解析。
- **增删改**：单击选中，双击条目改名，条目右侧 × 删除；顶部搜索框按名称/分组即时筛选（几百条也秒筛）。
- 支持分隔符：逗号、分号、制表符、空格；表头、注释行（`#` 开头）都能处理。

### 2.2 计算

选一条反射率 + 一个光源，右侧立刻给出：

- XYZ、Lab、LCh
- sRGB、Display P3、Adobe RGB (1998)、ITU-R BT.2020，同时给 0~1 和 8bit 值，并标注是否超出色域
- HEX、色块预览（可按任一空间显示）
- 光谱曲线（可选叠加光源，光源按峰值归一画虚线）
- 参考白点（完美漫反射体的 XYZ）和实际积分区间

### 2.4 批量模拟

面板「批量模拟」两种模式，结果色块按网格排列，点击任一色块把该组合加载到上方详情：

- **多反射率 × 单光源**：勾选多条反射率，按当前光源统一算，网格里每格 = 一条反射率
- **单反射率 × 多光源**：勾选多个光源（内置 59 个 + 库里的），按当前反射率统一算，网格里每格 = 一个光源

每格显示色块 + 名称 + Lab；超出当前显示空间色域的色块右上角有红点标记。

批量面板的工具：

- **每行 N 个**：自定义网格列数（0 = 自动铺满）
- **按位置排布**：给反射率设了「分组 + 行 + 列」后，把色块按 (卡, 行, 列) 还原成一张张色卡；
  空位显示为虚线空单元格，未设位置或位置越界的条目排在卡下方
- **分组全选**：反射率按「卡」（group 字段）分组、光源按「标准 / 荧光 / LED / 高压放电 / 我的库」分组，
  一键整组勾选
- **显示 ΔE00**：勾选后每格显示它与「实测颜色」的 ΔE00。只对固定实测色（Lab/XYZ 或 RGB）生效；
  实测光谱不参与批量（光谱要绑定光源，多光源模式下无定义）
- **曲线对比**：把勾选的多条反射率（或多条光源）叠到同一张图上，不同颜色 + 图例；光源各自峰值归一到 1 比形状
- **预设**：把当前勾选集合命名保存，下拉一键载入（反射率、光源通用）
- **导出批量结果**：把当前网格所有组合导成一张 CSV，每行 = 反射率 / 光源 / 分组 / 行 / 列 / 观察者 / XYZ / Lab / 各空间 RGB / HEX / 超色域 / ΔE00

### 2.3 实测对比

录入实测颜色，与模拟值算 ΔE00 / ΔE76：

- **Lab / XYZ**：直接填数值
- **RGB**：填 RGB + 选色彩空间 + 选量程（0~255 或 0~1）
- **光谱**：粘贴一条实测光谱，按当前光源和观察者重新算

## 3. 计算口径（重要）

数值要能复现，口径必须写死。本工具固定如下：

| 项目 | 口径 |
|---|---|
| 积分方法 | 矩形法，`k = 100 / Σ S(λ)·ȳ(λ)·Δλ`，`XYZ = k·Σ S(λ)·R(λ)·x̄(λ)·Δλ` |
| 积分网格 | 1nm 等间隔，取反射率 / 光源 / 观察者三者的公共波长区间；光源（5nm）与反射率按线性插值到 1nm |
| 归一化 | 相对色度，Y 归一化到 100（不做绝对亮度） |
| 观察者 | CIE 1931 2° 或 CIE 1964 10°，可切换 |
| 参考白 | 完美漫反射体在该光源下的 XYZ，**与样品同波长网格**积分 |
| 色适应 | 默认开：Bradford，把光源白点适应到显示空间白点（相当于白平衡）。可关 |
| 色差 | CIEDE2000 为主，ΔE76 为辅 |

**为什么默认开色适应**：不开的话，A 光源下白纸会被算成橙红色块（那是「相机未白平衡」
的视图）。开了之后，白纸在 A 光下仍然是中性白，符合人眼所见。两种视图都有用，
所以做成开关，界面上会随开关切换口径说明。

**采样精度提醒**：内置光源是 300–780nm / 5nm 的 CIE 标准数据。荧光灯（FL）和 LED
有窄发射峰，5nm 数据插值到 1nm 会略微低估峰值能量。如果你的实测 SPD 有 1nm 精度，
直接导入 1nm 数据，本工具会用你给的精度积分。

**不做的事**：整图渲染（spectral rendering）、同色异谱指数、曲线编辑、仪器直连。

## 4. 数值可信度

`colorimetry.js` 不是自己编的公式，是照着 colour-science（0.4.7）实现的，并用它做
回归测试：84 个算例 × （7 种光源 × 2 种观察者 × 6 条反射率 × 3 个色彩空间）、
24 个色差对、14 个白点，色适应开 / 关两套。

```
./test/run.sh
与 colour-science 的最大偏差：
  XYZ                4.89e-3   (0~100 刻度)
  Lab                8.94e-3
  RGB                1.41e-4   (0~1 刻度)
  RGB（色适应后）     1.12e-4
  ΔE00 / ΔE76        2.31e-14
  白点               1.91e-6
```

残差全部来自内置数据的小数位舍入（CMF 保留 7 位、光源保留 4 位）。

## 5. 数据结构

`library.json` 就是一个数组，纯文本，可以放进 git：

```json
{
  "version": 1,
  "items": [
    {
      "id": "i1a2b3c",
      "kind": "reflectance",        // reflectance | illuminant
      "name": "白纸（亚光）",
      "start": 380,                  // 起始波长 nm
      "step": 5,                     // 步长 nm
      "values": [0.78, 0.786, ...],  // 反射率存 0~1；光源存相对值
      "group": "卡A",                // 可选：色卡/分组编号，用于按位置排布与分组全选
      "row": 3,                      // 可选：在卡里的行（从 1 起）
      "col": 4,                      // 可选：在卡里的列（从 1 起）
      "source": "csv",
      "createdAt": "2026-11-02T..."
    }
  ]
}
```

反射率一律存 0~1（导入 0~100% 时自动除以 100）；光源存相对值，不做归一化。
`group` / `row` / `col` 三个字段可选：写了 `group` 就能按卡分组，`row`+`col` 一起写才参与「按位置排布」
的网格摆放。批量导入几百条时，直接用脚本往这三列填值再「导入库」即可，不必在界面上逐条点。

## 6. 文件说明

```
index.html        界面结构
styles.css        样式
app.js            界面逻辑：库管理、导入向导、渲染、对比
colorimetry.js    色度学核心：积分、XYZ/Lab、RGB、色差、色适应
csv.js            CSV 解析、格式猜测、重采样
core.js           CIE 数据快照（59 个光源、2°/10° 观察者、4 个色彩空间矩阵）
data/             （可选）你把导出的 library.json 放这里做版本管理
tools/gen_core.py       从 colour-science 重新生成 core.js
tools/gen_reference.py  生成测试参考值 test/reference.json
test/parity.mjs         与 colour-science 的一致性测试
test/csv.test.mjs       CSV 解析测试
test/fixtures/          测试用 CSV 样例（百分比 / SPD / 单列 / 分号 + 序号列）
```

### 重新生成 CIE 数据

只有需要升级 colour-science 或换数据源时才用：

```sh
python3 -m venv .venv
./.venv/bin/pip install colour-science
./.venv/bin/python tools/gen_core.py        # → core.js
./.venv/bin/python tools/gen_reference.py   # → test/reference.json
./test/run.sh
```

Python 只在这个环节用到，运行网页时完全不需要。

## 7. 已知限制

1. **显示器不可信**：色块受操作系统色彩管理和显示器色域的影響，不同机器上看起来不一样。
   精确判断请以 Lab 数值和 ΔE 为准，色块只作直观参考。
2. **超出色域**：光谱颜色常超出 sRGB/P3。超出时色块会被裁剪显示并打「超色域」标记，
   数值表里保留未裁剪的原始值。
3. **库存在浏览器里**：清缓存会丢，务必定期「导出库」。
4. **实测 RGB 的解释**：按当前光源白点解释，即假定它已经白平衡到当前光源。如果是别的
   光源下拍的，请改用 Lab 输入。
5. **单色块**：一次算一个（光源, 反射率）组合，不支持整图渲染。
